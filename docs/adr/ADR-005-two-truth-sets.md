# ADR-005. Сверка сразу с двумя эталонами

**Решение:** hap.py запускается scatter по двум эталонам GIAB: v5.0q (основной) и v4.2.1.

**Контекст.** v5.0q построен по сборке генома HG002 и покрывает сложные участки; NIST помечает v4.2.1 для HG002 как устаревший. Но почти вся литература 2020–2025 годов использует v4.2.1, и без него цифры не с чем сравнить.

**Последствия.** Разница между эталонами (F1 инделов 0.98 против 0.91) показывает, сколько ошибок прячется в участках, которые старый эталон не оценивал. Порог качества задан для каждого эталона отдельно. Новый эталон, например российский эталонный образец, добавляется третьим элементом списка в job-файле без правки CWL.

**Проверка.** `pipeline:hg002` в GitLab CI; оба эталона в отчёте и в `evidence.json`.
