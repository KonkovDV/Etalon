# Иллюстрации главной страницы сайта

Шесть иллюстраций для главной страницы сайта (`scripts/build_site.py`). У каждого два файла WebP: `имя.webp` (1536 px) и `имя-768.webp` (768 px). Браузер выбирает размер по ширине экрана (`srcset`), поэтому на телефоне страница весит меньше. Первое фото загружается сразу, остальные — когда до них долистают. Тест `test_overview_photos_have_alt_text_and_both_sizes` проверяет, что на месте оба файла и у каждого фото есть описание в `alt`.

| Файл | Раздел главной | Сюжет |
|---|---|---|
| `workplace` | первый экран | рабочее место у окна с видом на осенний парк: ноутбук, два монитора с графиками, стеклянная модель ДНК |
| `team` | вакансия | четверо коллег обсуждают графики у экрана |
| `lab` | точность WGS | учёная ставит пробирку в секвенатор |
| `family` | база частот | три поколения одной семьи гуляют по осеннему парку |
| `twins` | воспроизводимость | две одинаковые стеклянные модели ДНК |
| `report` | документы | справка на одной странице в руках у читателя |

Пересборка из исходных PNG 1536 × 1024 (Pillow, качество 80):

```python
from PIL import Image

im = Image.open("workplace.png").convert("RGB")
im.save("workplace.webp", "WEBP", quality=80, method=6)
im.resize((768, 512), Image.LANCZOS).save("workplace-768.webp", "WEBP", quality=80, method=6)
```
