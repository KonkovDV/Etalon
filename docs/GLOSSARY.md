# Словарь терминов

Термины генетики, секвенирования и биоинформатики, которые встречаются в документах Etalon, — коротко и простыми словами. У каждого термина указано, где он работает в проекте.

## Генетика и молекулярная биология

| Термин | Что это | В проекте |
|---|---|---|
| Геном | вся ДНК организма; у человека — около 3 млрд пар оснований в 22 парах аутосом, паре половых хромосом и митохондриальной ДНК | оценка вычислений и хранения на геном 30x ([C-13](../CLAIMS_REGISTRY.md), [C-30](../CLAIMS_REGISTRY.md)) |
| ДНК, основания | молекула из двух комплементарных цепей; «буквы» A, C, G, T спариваются как A–T и G–C | риды и референс — последовательности этих букв |
| Хромосома | одна длинная молекула ДНК с белками; хромосомы нумеруются от 1 до 22, плюс X и Y | WGS — участок хромосомы 20, RNA-seq — гены хромосомы 22 |
| Ген, экзон | участок ДНК, по которому строится РНК; экзоны — части гена, которые остаются в зрелой мРНК | гены *SNAP25*, *MKKS* и *JAG1* в участке WGS ([METHODOLOGY](METHODOLOGY.md#образец-и-участок)) |
| Аллель, генотип | вариант последовательности в одной позиции; генотип — пара аллелей от матери и отца | генотипы сверяются с эталоном и метрикой F ([METRICS](METRICS.md)) |
| Гомозигота, гетерозигота | обе копии позиции одинаковы (1/1) или различаются (0/1) | частота гетерозигот в когорте должна быть 0,5 ([AGGREGATION](AGGREGATION.md)) |
| SNV, индел | замена одного основания; короткая вставка или делеция | точность считается отдельно для SNV и инделов |
| Гаплотип, фаза | набор аллелей на одной хромосоме; фаза — какие аллели лежат на одной хромосоме | один и тот же гаплотип разные программы записывают по-разному ([AGGREGATION](AGGREGATION.md)) |
| Транзиции и трансверсии (Ti/Tv) | замены внутри пуринов (A↔G) или пиримидинов (C↔T) — транзиции, остальные — трансверсии; у SNV генома Ti/Tv ≈ 2,0–2,1, а у случайных ошибок ≈ 0,5 | Ti/Tv <!--ev:ts_tv-->2.19<!--/ev--> при 2.18 у эталона — признак чистых вызовов |
| 8-оксогуанин (8-oxoG) | окисленный гуанин, который спаривается с аденином и даёт ложные замены G>T (C>A на другой цепи) | тест Фишера по спектру замен: p = <!--ev:oxog_fisher_p-->0.58<!--/ev-->, следов окисления нет |
| РНК, мРНК, экспрессия | РНК — копия участка ДНК; мРНК несёт инструкцию для белка; экспрессия гена — сколько его мРНК в клетке | RNA-seq считает фрагменты на ген ([RNASEQ](RNASEQ.md)) |
| Тандемный повтор, гомополимер | подряд идущие копии короткого мотива, например (CA)n; серия одного основания, например AAAAAAA | здесь вызов вариантов ошибается чаще всего ([C-03](../CLAIMS_REGISTRY.md)) |
| Сегментная дупликация | длинные (от 1 тыс. оснований) почти одинаковые копии участков генома | одна из стратификаций GIAB |

## Секвенирование

| Термин | Что это | В проекте |
|---|---|---|
| Высокопроизводительное секвенирование (NGS) | одновременное чтение миллионов коротких фрагментов ДНК или РНК | исходные данные обоих пайплайнов |
| WGS | полногеномное секвенирование: читается весь геном, а не только экзоны | пайплайн WGS на HG002 |
| RNA-seq | секвенирование РНК: по числу ридов на ген оценивается его экспрессия | пайплайн RNA-seq на UHR и HBR |
| Библиотека | фрагменты ДНК или РНК с адаптерами, готовые к секвенированию | дубликаты и длина вставки — свойства библиотеки |
| PCR-free | библиотека без ПЦР-амплификации: меньше дубликатов и ошибок в гомополимерах | данные HG002 — PCR-free, NovaSeq 6000 |
| Рид, парные риды | последовательность, прочитанная прибором; парные риды — оба конца одного фрагмента (2×151 — по 151 основанию) | вход пайплайна — парные FASTQ |
| Длина вставки | длина фрагмента между адаптерами | ошибка fastp в гистограмме вставки ([D-23](DEBUGGING.md#d-23)) |
| Качество основания (Phred) | Q = −10·lg p, где p — вероятность ошибки: Q20 — одна ошибка на 100 оснований, Q30 — на 1000 | `-Q 20` в вызове вариантов |
| Дубликаты: ПЦР и оптические | копии одного фрагмента: от амплификации при подготовке библиотеки или от соседних кластеров на проточной ячейке | считаются раздельно ([D-06](DEBUGGING.md#d-06)) |
| Проточная ячейка с нанолунками | ячейка NovaSeq, где кластеры растут в упорядоченных лунках | `samtools markdup -d 2500` для оптических дубликатов |
| Двухцветная химия, хвосты poly-G | NovaSeq кодирует G отсутствием сигнала, поэтому конец сигнала читается как G с высоким качеством | fastp срезает хвосты poly-G |
| Глубина покрытия | сколько ридов в среднем перекрывают одно основание; 35x — около 35 ридов | средняя глубина <!--ev:mean_depth-->34.5<!--/ev-->x; серия 5–35x ([METRICS](METRICS.md#f-и-глубина)) |
| Сверхдисперсия глубины | разброс глубины больше пуассоновского — из-за GC-смещения и амплификации | индекс дисперсии <!--ev:dispersion_index-->1.32<!--/ev--> |
| Spike-in | синтетические молекулы известной концентрации, добавленные в образец как внутренний эталон | ERCC в RNA-seq |

## Обработка данных

| Термин | Что это | В проекте |
|---|---|---|
| FASTQ | текстовый формат ридов вместе с качеством каждого основания | вход обоих пайплайнов |
| Референсный геном | эталонная последовательность генома, к которой выравниваются риды: GRCh38 (2013), полная сборка T2T-CHM13 (2022), российская GRCh38.rus (2026) | GRCh38; референс задаётся в job-файле |
| Выравнивание (картирование) | поиск места каждого рида в референсе | bwa-mem2 для ДНК, STAR для РНК |
| BAM, CRAM | форматы выравниваний; CRAM хранит риды относительно референса и без потерь сжимает сильнее | CRAM 3.1 — <!--ev:cram_v31_share-->29<!--/ev--> % объёма BAM ([C-30](../CLAIMS_REGISTRY.md)) |
| Вызов вариантов | определение по выравниваниям, где и какие варианты есть у образца | bcftools, Strelka2 и DeepVariant на одном BAM |
| VCF, gVCF | формат вариантов; gVCF описывает и позиции без вариантов, поэтому видно, где генотип известен | AN по gVCF ([AGGREGATION](AGGREGATION.md)) |
| Нормализация вариантов | приведение записи к одному виду: разбиение мультиаллельных записей и сдвиг инделов влево | `bcftools norm -m -any -f ref` перед сверкой |
| PASS, GQ, AD, DP | вызов прошёл фильтры; качество генотипа; глубина по каждому аллелю; общая глубина | фильтры метрики F и базы частот |

## Эталоны и точность

| Термин | Что это | В проекте |
|---|---|---|
| Эталонный образец | биоматериал с известным ответом; HG002 (NIST RM 8391) — сын из ашкеназского трио Personal Genome Project | WGS сверяется с HG002 |
| Эталонный набор вариантов | список вариантов эталонного образца, которому можно доверять: GIAB v5.0q построен по полной сборке генома HG002, v4.2.1 — предыдущий | оба эталона в одном прогоне ([ADR-005](adr/ADR-005-two-truth-sets.md)) |
| Доверенные участки | участки генома, где эталонный набор полон; точность считается внутри них | BED-файлы эталонов |
| Стратификации GIAB | разметка генома по трудности: повторы, гомополимеры, низкая картируемость, сегментные дупликации, крайний GC | точность по восьми стратам |
| TP, FP, FN | найденный истинный вариант; лишний вызов; пропущенный вариант | таблицы hap.py |
| Recall, precision, F1 | доля найденных истинных вариантов; доля истинных среди вызовов; их гармоническое среднее | SNV F1 <!--ev:strelka2_snp_v5_f1-->0.9955<!--/ev--> у Strelka2 |
| 95 % доверительный интервал | диапазон значений, совместимых с данными при этом объёме выборки; для долей — интервал Уилсона | интервалы у всех долей и F1 ([METHODOLOGY](METHODOLOGY.md#статистика)) |
| Тест Макнемара | парный тест для двух программ на одних и тех же истинных вариантах | Strelka2 против bcftools: p = <!--ev:mcnemar_snp_v5_strelka2_bcftools_p-->0.013<!--/ev--> |
| GA4GH, hap.py | стандарт сравнения вызовов с эталоном по гаплотипам и его реализация | сверка в каждом прогоне |
| Метрика F (патент RU 2846268) | доля верных генотипов среди вызовов, совпавших с эталоном; порог приёмки 99,9 % | посчитана рядом с GA4GH ([METRICS](METRICS.md)) |
| ERCC | 92 синтетические РНК известной концентрации (External RNA Controls Consortium) в смесях Mix 1 и Mix 2 | линейность и кратность RNA-seq ([C-21](../CLAIMS_REGISTRY.md), [C-22](../CLAIMS_REGISTRY.md)) |
| UHR, HBR | эталонные РНК: универсальная (смесь клеточных линий) и РНК мозга человека | образцы RNA-seq, по три реплики |
| Кратность изменения, CPM | во сколько раз экспрессия различается между образцами; число фрагментов на миллион | кратность UHR/HBR по ERCC, корреляция <!--ev:rnaseq_fc_pearson-->0.984<!--/ev--> |

## База популяционных частот

| Термин | Что это | В проекте |
|---|---|---|
| AC, AN, AF | число альтернативных аллелей в когорте; число учтённых аллелей (по два на образец с известным генотипом); частота AF = AC / AN | представление `v_allele_frequency_callable` в базе результатов |
| Когорта | группа людей, по геномам которых строится база частот | массив задач Slurm по когорте ([CLUSTER](CLUSTER.md#когорта)) |
| Совместное генотипирование | вызов генотипов сразу по всем образцам когорты, обычно по их gVCF | следующий шаг ([ROADMAP](ROADMAP.md)) |
